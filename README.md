# Python Data Lecture

Bài giảng NumPy và Pandas bằng tiếng Việt. Giao diện tối giản, responsive, mục lục tìm kiếm và sao chép ví dụ mã.

Mở `dist/index.html` để đọc. Có thể phục vụ thư mục `dist` bằng máy chủ web tĩnh. Không cần cài dependencies.

Nội dung được chuyển từ notebook do người dùng cung cấp. Ví dụ mã được hiển thị, không thực thi trên trang.
